# סדרן קולנוע – סורק QR לכיסאות

אפליקציית ווב (HTML סטטי, בלי שרת) שנפתחת בספארי באייפון, סורקת קוד QR שעל הכרטיס ומציגה את מספר הכיסא (1–14) ואת מיקומו במפת האולם.

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | אפליקציית הסורק |
| `print.html` | דף הדפסה של 14 הכרטיסים עם קודי ה־QR |
| `qr/seat-01..14.svg/png` | הקודים עצמם כקבצים |
| `seats.js` | המיפוי: תוכן הקוד ← מספר כיסא |
| `vendor/jsQR.js` | ספריית פענוח QR (Apache-2.0), מקומית כך שאין תלות באינטרנט |

כל קוד מכיל מזהה אקראי (למשל `CINEMA-SEAT:R3EP82`) ולא את המספר עצמו; האפליקציה מתרגמת אותו למספר כיסא. קוד שאינו ברשימה מוצג כ"קוד לא מוכר", וסריקה חוזרת של אותו כיסא מסומנת כ"כרטיס כבר נסרק".

## פתיחה באייפון
ספארי מאפשר גישה למצלמה רק בכתובת **https**. יש להעלות את התיקייה `cinema-usher` לכל אחסון סטטי, למשל:
- **GitHub Pages**: בריפו חדש, מעתיקים את תוכן התיקייה לשורש, ובהגדרות: Settings → Pages → Deploy from branch.
- **Netlify Drop**: גוררים את התיקייה אל app.netlify.com/drop.

אחר כך פותחים את הכתובת באייפון, לוחצים "הפעלת מצלמה" ומאשרים. אפשר גם Share → "הוספה למסך הבית" כדי שהאפליקציה תיפתח במסך מלא.

## בדיקה מקומית
```
cd cinema-usher && python3 -m http.server 8000
```
(בדפדפן במחשב `localhost` נחשב מאובטח, כך שגם שם המצלמה תעבוד.)
